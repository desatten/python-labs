Лабораторная работа №5. Двумерные массивы и функции. Вариант 2

Оба пункта по методичке:
1. Определить количество столбцов, не содержащих ни одного нулевого элемента.
2. Переставить строки по возрастанию характеристик. Характеристика строки — сумма положительных чётных элементов.

Размеры матрицы вводятся пользователем. Элементы формируются автоматически. Все пункты оформлены функциями; глобальные переменные внутри функций не используются.

Запуск: python main.py

Проверочный пример для функций:
Матрица:
2 0 4
1 3 5
6 8 0

Столбцов без нулей: 1 (первый столбец).
Характеристики строк: 6, 0, 14.
Порядок строк после сортировки: вторая, первая, третья.
