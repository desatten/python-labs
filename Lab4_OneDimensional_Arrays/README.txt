Лабораторная работа №4 — Одномерные массивы, вариант 2

Программа формирует массив из N вещественных случайных чисел в диапазоне от -5 до 5 (N от 2 до 30).

Выполняются пункты варианта 2:
1. Вычисляется сумма положительных элементов.
2. Вычисляется произведение элементов, расположенных между максимальным по модулю и минимальным по модулю элементами.
3. Массив сортируется по убыванию.

Запуск: python main.py

Для проверки логики использован пример массива:
[1.5, -4.0, 2.0, -0.5, 3.0, -2.0]

Ожидаемые результаты:
Сумма положительных элементов: 6.50
Максимальный по модулю элемент: -4.00 (позиция 2)
Минимальный по модулю элемент: -0.50 (позиция 4)
Между ними находится число 2.00, произведение: 2.00
Сортировка по убыванию: [3.0, 2.0, 1.5, -0.5, -2.0, -4.0]

Если между элементами с максимальным и минимальным модулем нет чисел, произведение принимается равным 1.
