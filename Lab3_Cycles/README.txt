Лабораторная работа №3 — Организация циклов

В проекте три программы:
1. task1_graph_variant2.py — таблица значений графика варианта 2 из лабораторной №2, задания 1.
2. task2_random_shots.py — 10 случайных выстрелов по области варианта 2 из лабораторной №2, задания 2.
3. task3_item2_exp_minus_x.py — только пункт 2 задания 3: вычисление e^(-x) по ряду Тейлора.

Запуск:
python task1_graph_variant2.py
python task2_random_shots.py
python task3_item2_exp_minus_x.py

Тесты задания 1:
X начальное = -10; X конечное = 8; dx = 1. Интервал проходит через все участки графика.

Задание 2:
Выполняются 10 случайных испытаний. Координаты и попадания меняются при каждом запуске.

Тест задания 3, пункт 2:
X начальное = -2; X конечное = 2; dx = 0.5; epsilon = 0.0001.
Ориентировочные значения: e^2 = 7.389056; e^1 = 2.718282; e^0 = 1; e^(-1) = 0.367879; e^(-2) = 0.135335.

Примечание: для задания 1 использован график варианта 2, так как отдельный вариант для графика не был указан. Для задания 2 сохранена ранее выбранная область варианта 2.
